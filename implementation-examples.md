# Platform Router Agent

You are the Platform Router Agent for embedded C development. Your role is to:
1. Detect the target platform from project structure
2. Route queries to appropriate platform-specific agents
3. Provide platform-agnostic guidance when appropriate

## Platform Detection Strategy

### Detection Rules
1. **STM32**: Look for `stm32*.h`, `HAL_*`, `startup_stm32*.s`
2. **ESP32**: Look for `esp_*.h`, `sdkconfig`, `idf_component.yml`
3. **Nordic**: Look for `nrf*.h`, `sdk_config.h`, `nrf_*.c`
4. **Arduino**: Look for `*.ino`, `Arduino.h`
5. **Generic**: Fallback for unknown platforms

### Detection Code Pattern
```python
def detect_platform(project_path: Path) -> str:
    # Check for STM32
    if any(project_path.glob("**/stm32*.h")):
        return "stm32"
    
    # Check for ESP32
    if (project_path / "sdkconfig").exists():
        return "esp32"
    
    # Check for Nordic
    if any(project_path.glob("**/nrf*.h")):
        return "nordic"
    
    # Check for Arduino
    if any(project_path.glob("**/*.ino")):
        return "arduino"
    
    return "generic"
```

## Routing Logic

When you receive a query:

1. **Detect Platform** (if not already known)
   - Use `mcp__embedded-docs__detect_platform` tool
   - Cache result for session

2. **Analyze Query Domain**
   - Peripheral configuration → peripheral-comm agent
   - Power optimization → power-management agent
   - Debug/crash → debug agent
   - Security → security agent

3. **Route to Specialist**
   - Platform-specific: Route to platform specialist
   - Generic: Route to generic embedded agent
   - Multi-domain: Coordinate multiple agents

# UART Configuration Skill

## Description
Generates complete UART initialization code for the target platform with proper clock configuration, pin setup, and optional DMA/interrupt support.

## Inputs

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `platform` | string | Yes | - | Target platform (stm32, esp32, nordic, generic) |
| `uart_instance` | string | Yes | - | UART peripheral (e.g., USART1, UART0) |
| `baud_rate` | integer | Yes | - | Baud rate (e.g., 115200) |
| `data_bits` | integer | No | 8 | Data bits (7, 8, 9) |
| `parity` | string | No | "none" | Parity (none, even, odd) |
| `stop_bits` | float | No | 1.0 | Stop bits (1, 1.5, 2) |
| `flow_control` | string | No | "none" | Flow control (none, rts, cts, rts_cts) |
| `mode` | string | No | "polling" | Mode (polling, interrupt, dma) |
| `tx_pin` | string | No | auto | TX pin (e.g., PA9) |
| `rx_pin` | string | No | auto | RX pin (e.g., PA10) |

## Outputs

1. **Initialization Code**: Complete UART setup function
2. **Pin Configuration**: GPIO pin setup for TX/RX
3. **Clock Configuration**: Required clock settings
4. **Interrupt Handler**: ISR template (if interrupt mode)
5. **DMA Configuration**: DMA setup (if DMA mode)

### STM32 HAL Implementation

```c
/* UART Configuration for STM32 HAL */
/* Generated by uart-config skill v1.0.0 */

#include "stm32h7xx_hal.h"

/* UART Handle */
UART_HandleTypeDef huart1;

/**
 * @brief USART1 Initialization Function
 * @param None
 * @retval None
 */
void MX_USART1_UART_Init(void)
{
    huart1.Instance = USART1;
    huart1.Init.BaudRate = 115200;
    huart1.Init.WordLength = UART_WORDLENGTH_8B;
    huart1.Init.StopBits = UART_STOPBITS_1;
    huart1.Init.Parity = UART_PARITY_NONE;
    huart1.Init.Mode = UART_MODE_TX_RX;
    huart1.Init.HwFlowCtl = UART_HWCONTROL_NONE;
    huart1.Init.OverSampling = UART_OVERSAMPLING_16;
    huart1.Init.OneBitSampling = UART_ONE_BIT_SAMPLE_DISABLE;
    huart1.Init.ClockPrescaler = UART_PRESCALER_DIV1;
    huart1.AdvancedInit.AdvFeatureInit = UART_ADVFEATURE_NO_INIT;
    
    if (HAL_UART_Init(&huart1) != HAL_OK)
    {
        Error_Handler();
    }
    
    if (HAL_UARTEx_SetTxFifoThreshold(&huart1, UART_TXFIFO_THRESHOLD_1_8) != HAL_OK)
    {
        Error_Handler();
    }
    
    if (HAL_UARTEx_SetRxFifoThreshold(&huart1, UART_RXFIFO_THRESHOLD_1_8) != HAL_OK)
    {
        Error_Handler();
    }
    
    if (HAL_UARTEx_DisableFifoMode(&huart1) != HAL_OK)
    {
        Error_Handler();
    }
}

/**
 * @brief USART1 GPIO Configuration
 * @param None
 * @retval None
 */
void HAL_UART_MspInit(UART_HandleTypeDef* huart)
{
    GPIO_InitTypeDef GPIO_InitStruct = {0};
    
    if(huart->Instance == USART1)
    {
        /* Peripheral clock enable */
        __HAL_RCC_USART1_CLK_ENABLE();
        __HAL_RCC_GPIOA_CLK_ENABLE();
        
        /**USART1 GPIO Configuration
        PA9     ------> USART1_TX
        PA10    ------> USART1_RX
        */
        GPIO_InitStruct.Pin = GPIO_PIN_9|GPIO_PIN_10;
        GPIO_InitStruct.Mode = GPIO_MODE_AF_PP;
        GPIO_InitStruct.Pull = GPIO_NOPULL;
        GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
        GPIO_InitStruct.Alternate = GPIO_AF7_USART1;
        HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
    }
}

/* Usage Example */
void uart_example(void)
{
    uint8_t tx_data[] = "Hello, World!\r\n";
    uint8_t rx_data[100];
    
    /* Initialize UART */
    MX_USART1_UART_Init();
    
    /* Transmit data (polling mode) */
    HAL_UART_Transmit(&huart1, tx_data, sizeof(tx_data), HAL_MAX_DELAY);
    
    /* Receive data (polling mode) */
    HAL_UART_Receive(&huart1, rx_data, sizeof(rx_data), 1000);
}

### ESP32 ESP-IDF Implementation

```c
/* UART Configuration for ESP32 ESP-IDF */
/* Generated by uart-config skill v1.0.0 */

#include "driver/uart.h"
#include "driver/gpio.h"

#define UART_NUM        UART_NUM_1
#define UART_TX_PIN     GPIO_NUM_17
#define UART_RX_PIN     GPIO_NUM_16
#define UART_BUF_SIZE   1024

/**
 * @brief UART Initialization Function
 * @return ESP_OK on success
 */
esp_err_t uart_init(void)
{
    /* Configure UART parameters */
    uart_config_t uart_config = {
        .baud_rate = 115200,
        .data_bits = UART_DATA_8_BITS,
        .parity = UART_PARITY_DISABLE,
        .stop_bits = UART_STOP_BITS_1,
        .flow_ctrl = UART_HW_FLOWCTRL_DISABLE,
        .source_clk = UART_SCLK_DEFAULT,
    };
    
    /* Install UART driver */
    ESP_ERROR_CHECK(uart_driver_install(UART_NUM, UART_BUF_SIZE * 2, 0, 0, NULL, 0));
    ESP_ERROR_CHECK(uart_param_config(UART_NUM, &uart_config));
    ESP_ERROR_CHECK(uart_set_pin(UART_NUM, UART_TX_PIN, UART_RX_PIN, 
                                  UART_PIN_NO_CHANGE, UART_PIN_NO_CHANGE));
    
    return ESP_OK;
}

/* Usage Example */
void uart_example(void)
{
    const char* tx_data = "Hello, World!\r\n";
    uint8_t rx_data[128];
    
    /* Initialize UART */
    uart_init();
    
    /* Transmit data */
    uart_write_bytes(UART_NUM, tx_data, strlen(tx_data));
    
    /* Receive data (with timeout) */
    int len = uart_read_bytes(UART_NUM, rx_data, sizeof(rx_data), 
                              pdMS_TO_TICKS(1000));
    if (len > 0) {
        rx_data[len] = '\0';
        printf("Received: %s\n", rx_data);
    }
}

#include "nrf_drv_uart.h"
#include "app_error.h"

/* UART instance */
static const nrf_drv_uart_t uart_inst = NRF_DRV_UART_INSTANCE(0);

/* UART event handler */
static void uart_event_handler(nrf_drv_uart_event_t * p_event, void * p_context)
{
    switch (p_event->type)
    {
        case NRF_DRV_UART_EVT_TX_DONE:
            /* Transmission complete */
            break;
            
        case NRF_DRV_UART_EVT_RX_DONE:
            /* Reception complete */
            break;
            
        case NRF_DRV_UART_EVT_ERROR:
            /* Error occurred */
            break;
            
        default:
            break;
    }
}

/**
 * @brief UART Initialization Function
 * @return NRF_SUCCESS on success
 */
ret_code_t uart_init(void)
{
    nrf_drv_uart_config_t uart_config = NRF_DRV_UART_DEFAULT_CONFIG;
    uart_config.pseltxd = 6;  /* TX pin */
    uart_config.pselrxd = 8;  /* RX pin */
    uart_config.baudrate = NRF_UART_BAUDRATE_115200;
    uart_config.hwfc = NRF_UART_HWFC_DISABLED;
    uart_config.parity = NRF_UART_PARITY_EXCLUDED;
    
    ret_code_t err_code = nrf_drv_uart_init(&uart_inst, &uart_config, 
                                            uart_event_handler);
    APP_ERROR_CHECK(err_code);
    
    return err_code;
}

    /* Receive data */

   def validate_baud_rate(platform, baud_rate, clock_freq):

/* Always check buffer sizes */
void safe_copy(uint8_t *dest, const uint8_t *src, size_t dest_size, size_t src_size)
{
    size_t copy_size = (src_size < dest_size) ? src_size : dest_size;

/* Use atomic operations for shared variables */

## Common Patterns

### Peripheral Initialization Pattern
```c
/**
 * Standard peripheral initialization pattern
 * 1. Enable peripheral clock
 * 2. Configure GPIO pins
 * 3. Configure peripheral registers
 * 4. Enable interrupts (if needed)
 * 5. Enable peripheral
 */
void peripheral_init(void)
{
    /* 1. Clock enable */
    RCC->APBxENR |= RCC_APBxENR_PERIPHxEN;
    
    /* 2. GPIO configuration */
    gpio_init();
    
    /* 3. Peripheral configuration */
    PERIPH->CR1 = /* configuration */;
    
    /* 4. Interrupt enable */
    NVIC_EnableIRQ(PERIPH_IRQn);
    
    /* 5. Peripheral enable */
    PERIPH->CR1 |= PERIPH_CR1_EN;
}
```

### State Machine Pattern
```c
/**
 * State machine for embedded systems
 * Clear, maintainable, easy to debug
 */
typedef enum {
    STATE_IDLE,
    STATE_BUSY,
    STATE_ERROR
} system_state_t;

static system_state_t current_state = STATE_IDLE;

void state_machine_update(void)
{
    switch (current_state)
    {
        case STATE_IDLE:
            if (start_condition) {
                current_state = STATE_BUSY;
            }
            break;
            
        case STATE_BUSY:
            if (complete_condition) {
                current_state = STATE_IDLE;
            } else if (error_condition) {
                current_state = STATE_ERROR;
            }
            break;
            
        case STATE_ERROR:
            handle_error();
            current_state = STATE_IDLE;
            break;
    }
}

## Best Practices

### Always Do
✅ Check return values and error codes
✅ Use const for read-only data
✅ Use volatile for hardware registers
✅ Document hardware dependencies
✅ Include proper header guards
✅ Use fixed-width integer types (uint8_t, etc.)
✅ Consider endianness for multi-byte data

### Never Do
❌ Use dynamic memory allocation in ISRs
❌ Perform blocking operations in ISRs
❌ Ignore compiler warnings
❌ Use floating-point in time-critical code (unless FPU available)
❌ Access hardware registers without proper synchronization
❌ Assume memory is initialized to zero
❌ Use recursion without stack depth analysis

## 4. MCP Server Tool Implementation Example

```python
# mcp_server/tools/search.py

from typing import List, Optional
from dataclasses import dataclass

@dataclass
class SearchResult:
    """Result from documentation search"""
    content: str
    source: str
    platform: str
    relevance_score: float
    metadata: dict

class EmbeddedDocumentationTools:
    """MCP tools for embedded documentation search"""
    
    def __init__(self, store_manager):
        self.store_manager = store_manager
    
    async def search_embedded_docs(
        self,
        query: str,
        platform: Optional[str] = None,
        peripheral: Optional[str] = None,
        max_results: int = 5
    ) -> List[SearchResult]:
        """
        Search embedded documentation across platforms.
        
        Args:
            query: Search query
            platform: Filter by platform (stm32, esp32, nordic, etc.)
            peripheral: Filter by peripheral (uart, spi, i2c, etc.)
            max_results: Maximum number of results
            
        Returns:
            List of search results with relevance scores
        """
        # Auto-detect platform if not specified
        if not platform:
            platform = await self.store_manager.detect_platform()
        
        # Get appropriate store
        store = self.store_manager.get_store(platform)
        
        # Build search filters
        filters = {}
        if peripheral:
            filters['peripheral'] = peripheral
        
        # Perform hybrid search (vector + keyword)
        results = await store.hybrid_search(
            query=query,
            filters=filters,
            max_results=max_results
        )
        
        return results
    
    async def get_code_example(
        self,
        topic: str,
        platform: Optional[str] = None,
        language: str = "c"
    ) -> Optional[str]:
        """
        Get code example for a specific topic.
        
        Args:
            topic: Topic to find example for (e.g., "UART initialization")
            platform: Target platform
            language: Programming language (default: c)
            
        Returns:
            Code example or None if not found
        """
        if not platform:
            platform = await self.store_manager.detect_platform()
        
        store = self.store_manager.get_store(platform)
        
        # Search for code examples
        results = await store.search(
            query=f"{topic} code example",
            filters={'doc_type': 'code_example', 'language': language},
            max_results=1
        )
        
        if results:
            return results[0].content
        return None
    
    async def lookup_api_function(
        self,
        function_name: str,
        platform: Optional[str] = None
    ) -> Optional[dict]:
        """
        Look up API function documentation.
        
        Args:
            function_name: Function name (e.g., "HAL_UART_Init")
            platform: Target platform
            
        Returns:
            Function documentation with parameters, return value, etc.
        """
        if not platform:
            platform = await self.store_manager.detect_platform()
        
        store = self.store_manager.get_store(platform)
        
        # Search for function documentation
        results = await store.search(
            query=function_name,
            filters={'doc_type': 'api_reference'},
            max_results=1
        )
        
        if results:
            return {
                'name': function_name,
                'description': results[0].content,
                'platform': platform,
                'source': results[0].source
            }
        return None
    
    async def troubleshoot_issue(
        self,
        issue_description: str,
        platform: Optional[str] = None
    ) -> List[dict]:
        """
        Find solutions to common embedded issues.
        
        Args:
            issue_description: Description of the issue
            platform: Target platform
            
        Returns:
            List of potential solutions with explanations
        """
        if not platform:
            platform = await self.store_manager.detect_platform()
        
        store = self.store_manager.get_store(platform)
        
        # Search troubleshooting database
        results = await store.search(
            query=issue_description,
            filters={'doc_type': 'troubleshooting'},
            max_results=5
        )
        
        solutions = []
        for result in results:
            solutions.append({
                'issue': issue_description,
                'solution': result.content,
                'platform': platform,
                'confidence': result.relevance_score
            })
        
        return solutions
